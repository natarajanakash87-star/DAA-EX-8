Travelling Salesman Problem

Branch and Bound with Reduced Cost Matrix

Problem Statement

Given a 5-city Travelling Salesman Problem with a known cost matrix, find the minimum cost Hamiltonian cycle using the Branch and Bound technique.

A lower-bound estimation based on reduced cost matrices is used to eliminate branches that cannot produce a better solution.

Objectives

  • Implement the Travelling Salesman Problem.
  • Use Branch and Bound for optimization.
  • Calculate lower bounds using matrix reduction.
  • Prune non-promising branches.
  • Find the optimal Hamiltonian cycle.
  • Calculate the minimum tour cost.

Branch and Bound Approach

The Branch and Bound algorithm systematically explores possible tours while calculating a lower bound for every partial tour.

  1. Reduce every row of the cost matrix.
  2. Reduce every column of the matrix.
  3. Calculate the reduction cost.
  4. Branch by selecting an unvisited city.
  5. Calculate the lower bound of each branch.
  6. Discard branches whose lower bound is greater than the current best solution.
  7. Continue until an optimal Hamiltonian cycle is obtained.

Lower Bound

Lower Bound =
Current Cost
+ Matrix Reduction Cost

Row and column reduction ensures that every remaining row and column contains at least one zero. The sum of the reductions provides a lower-bound estimate for the remaining tour.

Optimal Tour

0 → 3 → 1 → 4 → 2 → 0

Minimum Tour Cost: 28

Cost Calculation


0 → 3 = 10

3 → 1 = 6

1 → 4 = 2

4 → 2 = 7

2 → 0 = 3

----------------

Total = 10 + 6 + 2 + 7 + 3

      = 28

Complexity Analysis

Parameter Complexity
Worst Case Time O(N!)
Space Complexity O(N²)

Branch and Bound can significantly reduce the practical search space through pruning, although the worst-case complexity remains factorial.
